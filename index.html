Git Branching & Merge Conflicts

This page is a small practice assignment for exploring Git branches and resolving a merge conflict.

What is a branch? A branch lets you develop a change independently before merging it into the main line of work.

Conflict resolution workflow

  1. Create a feature branch from main.
  2. Edit the same paragraph on both branches.
  3. Merge the feature branch and inspect the conflict markers.
  4. Combine the intended changes, then commit the resolution.

Resolution: Feature branch: test the change independently before merging.
